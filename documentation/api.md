# API

Base path: `/api/v1`. JSON only.

## Conventions

| Topic        | Rule                                                                                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Success body | `{ "data": … }` (lists: `{ "data": [...], "meta": { page, pageSize, total } }`)                                                                          |
| Error body   | `{ "error": { "code", "message", "details"?, "requestId" } }`                                                                                            |
| Money        | `{ "amountMinor": "125050", "currency": "GHS" }`. Amounts are always strings.                                                                            |
| Request ID   | Every response carries `X-Request-Id`. Quote it in support tickets.                                                                                      |
| Idempotency  | Financial `POST`s require an `Idempotency-Key` header. Replays return the original response with `Idempotency-Replayed: true` (see financial-ledger.md). |
| Pagination   | `?page=1&pageSize=25` (max 100), `?sort=field:asc`                                                                                                       |
| Rate limits  | IETF draft-8 `RateLimit` headers. `429` with code `RATE_LIMITED`.                                                                                        |
| Auth         | httpOnly session cookie plus an `X-CSRF-Token` header on state-changing requests (see authentication.md)                                                 |

### Error codes

`VALIDATION_ERROR` (422) · `MALFORMED_JSON` (400) · `UNAUTHENTICATED` (401) · `INVALID_CREDENTIALS` (401) · `MFA_REQUIRED` / `MFA_INVALID` / `MFA_LOCKED` (401) · `CSRF_INVALID` / `MFA_ENROLLMENT_REQUIRED` / `EMAIL_NOT_VERIFIED` / `ACCOUNT_DISABLED` (403) · `TOKEN_INVALID` (400) · `SEPARATION_OF_DUTIES` (409) · `FORBIDDEN` (403) · `CORS_REJECTED` (403) ·
`NOT_FOUND` (404) · `CONFLICT` (409) · `PAYLOAD_TOO_LARGE` (413) · `RATE_LIMITED` (429) · `INTERNAL_ERROR` (500) ·
`SERVICE_UNAVAILABLE` (503)
